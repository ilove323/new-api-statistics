# New API Statistics 0.1.0

首个正式版本，为 New API 提供用量统计、成本分析与余额报警。
维护者：ilove323。许可证：Apache-2.0。

## 使用前提

**必须已有 New API，且使用 PostgreSQL 数据库。**
本项目复用 New API 管理员账号，不能脱离 New API 独立使用。
统计查询读取原数据库；额度、归档和报警写入单独的监控数据库。

## 主要功能

- 用户、模型用量与消费排名，输入、输出及缓存 Token 明细。
- 精确到秒的时间筛选、多工作表 Excel 导出。
- 预算设置、历史月份归档、每日北京时间 10:00 余额检查。
- 飞书与钉钉企业应用通知、结构化报警 API。
- 版本化监控库迁移、AMD64/ARM64 容器镜像。

## 安装

镜像：`ghcr.io/ilove323/new-api-statistics:0.1.0`。

下载本 Release 的 `compose.release.yml`、`.env.example`、`nginx.conf.example`。
将 `.env.example` 复制为 `.env` 并填写数据库与网络参数，设置 `IMAGE_TAG=0.1.0`：

```bash
docker compose -f compose.release.yml up -d
```

通过现有 Nginx 转发 `/statistics/`，使用 New API 管理员账号登录。
详细建库 SQL、网络与直接端口访问见
[部署文档](https://github.com/ilove323/new-api-statistics/blob/v0.1.0/docs/deployment.md)、
[监控库初始化](https://github.com/ilove323/new-api-statistics/blob/v0.1.0/docs/monitoring.md)。

## 从未发版版本升级

- 备份独立监控库、部署配置及通知加密密钥。
- Docker Compose 中 worker 入口改为 `python -m new_api_statistics.balance_worker`；
  Gunicorn 入口改为 `new_api_statistics.app:app`，本版配置已同步。
- 首次启动自动登记迁移版本，兼容此前未建版本表的监控库。
- 迁移可能删除旧版已读记录和迁移后的旧凭据字段；回退时可能需要恢复数据库备份。

## 统计口径

目前根据模型名称约定缓存包含关系；部分报表数值包含数学折算，
不是对原始流量的重放。实际消费金额来自 New API 消费日志。
接入自定义 fork 前，请核对
[兼容范围](https://github.com/ilove323/new-api-statistics/blob/v0.1.0/docs/compatibility.md)
和[统计口径](https://github.com/ilove323/new-api-statistics/blob/v0.1.0/docs/calculation.md)。
